# WBN FMS — Simulator

Local copy of the FMS Haul-Road Simulator to work on.

## Run it

```bash
pip install flask
python serve.py
```

Open **https://wbn-fms-mac.ngrok.app/simulator**

Keep that terminal running while you work; use a second terminal for git.

It runs on **sample data** out of the box — no setup, no database needed.

## Files

| File | Edit this for… |
|---|---|
| `templates/simulator.html` | the page — layout, charts, styling, interactions |
| `simulator_api.py` | the calculations behind the data |

Commit and push your changes when done.
